Bean Cake (Akara) Recipe – freeCodeCamp Project

This project was one of my first HTML/CSS builds during my freeCodeCamp journey. It is a simple recipe page showcasing semantic HTML structure and foundational CSS styling.

Overview :

The page presents a traditional West African dish — Bean Cake (Akara) — including:

- A short description of the dish  
- An ingredients list (unordered list)  
- Step-by-step cooking instructions (ordered list)  
- An image with caption using `<figure>` and `<figcaption>`

Key Concepts Practiced :

- Semantic HTML elements (`<section>`, `<figure>`, `<footer>`)
- Proper use of ordered and unordered lists
- Basic CSS styling (background images, box shadows, border radius)
- Content layout using width and margin auto-centering

Tech Stack :

- HTML5  
- CSS3

Purpose

This project represents the starting point of my frontend development journey. It reflects my early understanding of structure, layout, and styling — and serves as a reference point for how far my skills have evolved since then.
